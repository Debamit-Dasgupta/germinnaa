# GERMINNAA single-page website

## Direction
Build a cinematic, editorial restaurant experience centered on Germinnaa’s deep emerald, warm ivory, and restrained antique-gold identity. The uploaded mark will anchor the navigation and footer, paired with a refined GERMINNAA wordmark treatment. Photography will feel intimate, warm, and specific to contemporary dining in Kolkata rather than stock-template hospitality.

## Page experience
- Create a sticky translucent navigation with smooth section links, a gold-outline reservation action, and an accessible mobile menu.
- Build a full-viewport photographic opening with the supplied headline, two working scroll actions, subtle emerald treatment, and a restrained scroll cue.
- Follow with the requested editorial story split, three image-led visit occasions, curated “Worth Trying” dishes, and a full-width cinematic statement.
- Present the four reasons guests return as a flowing horizontal story rather than a conventional feature-card grid.
- Add a quiet editorial review section using only clearly framed sentiment themes—no invented reviewer names, quotes, ratings, or platform claims.
- Create an asymmetric visual diary for food, coffee, drinks, interiors, and shared moments, with a working Instagram link to `@germinnaa`.
- Finish with the full address, hours, phone, directions, embedded Google Map, reservation action, emotional closing statement, and compact footer.

## Visual system and imagery
- Use the exact palette: emerald `#004B44`, antique gold `#C09658`, ivory `#F5F0E6`, cream `#EAE3D6`, charcoal `#151817`, and warm grey `#8C8B84`, translated into semantic theme tokens.
- Pair an elegant editorial serif with a clean contemporary sans-serif, loaded correctly and applied consistently.
- Generate a cohesive set of premium restaurant and food photographs for the opening, story, experiences, signature dishes, statement image, and gallery; optimize and lazy-load non-critical imagery.
- Use fine rules, subtle grain, carefully controlled corner radii, generous spacing, and restrained depth. Avoid gradients, generic cards, loud gold, and generic restaurant iconography.
- Add refined reveal, image-zoom, line-draw, and limited parallax motion with reduced-motion support.

## Functional interactions
- Build an accessible reservation dialog collecting name, phone, date, time, and guest count with client-side schema validation and a polished confirmation state. It will be structured for later WhatsApp, email, calendar, or reservation-service delivery without pretending a booking was transmitted.
- Build a menu dialog with the curated featured items and an external-link-ready “full menu” action, without inventing prices.
- Make phone, directions, Instagram, navigation, and all section actions work.
- Connect Google Maps and render the Germinnaa location with a reliable marker and directions handoff.
- Add keyboard navigation, visible focus states, semantic landmarks, descriptive alternative text, and touch-friendly controls.

## Mobile and quality checks
- Compose mobile layouts independently: readable editorial type, safe image crops, spacious stacking, an adaptive gallery, and no horizontal overflow.
- Verify desktop and mobile rendering, menu behavior, reservation validation and confirmation, scrolling, links, map display, image loading, and reduced-motion behavior in the live preview.
- Add page-specific search and social metadata plus Restaurant/LocalBusiness structured data using the supplied verified address, hours, phone, and cuisine positioning.

## Scope note
The reservation form will be fully interactive but will not persist or send bookings until a delivery service is chosen. Public review ratings, attributed testimonials, and live Instagram posts will not be fabricated; the design will remain ready for verified sources later.
