# Germinnaa Experience

Create a fully functional, premium, highly polished, single-page restaurant website for GERMINNAA, a fine-dining / contemporary café restaurant located in Southern Avenue, Kolkata.

This must NOT look like a generic restaurant template.

The website should immediately make someone feel:

“This place looks beautiful. I trust it. I want to visit it.”

The overall experience should feel warm, intimate, premium, artistic, sophisticated, modern and emotionally inviting — like discovering a hidden culinary gem in Kolkata.

🏆 BRAND UNDERSTANDING

Germinnaa is a contemporary dining destination known for its:

Premium yet welcoming atmosphere
Cozy, elegant and aesthetically pleasing ambience
European, Continental, Italian and globally inspired cuisine
Carefully crafted food and beverages
Pizza, grilled dishes, hummus, seafood, desserts, coffee and cocktails/mocktails
Warm hospitality
Romantic date-friendly atmosphere
Relaxed gatherings with friends and family

The brand should feel like:

Soft warmth × Slow indulgence × Thoughtful flavours × Beautiful moments

Avoid making it look overly luxurious like a five-star hotel.

Avoid making it look like a loud café, fast-food restaurant, nightclub, or generic food-delivery website.

The visual personality should be:

Quiet confidence. Warm sophistication. Modern intimacy.

Large desktop screens

Images should not crop important subjects
Navigation should be easy
Buttons should be thumb-friendly
No horizontal scrolling
Sections should remain spacious
Gallery should intelligently rearrange
Animations should remain smooth

The mobile version should feel like a premium experience designed specifically for mobile, not a squeezed desktop website.

❌ Flashing animations
